# Rockfleet browser preview

This is the first public browser-facing An Turas exhibit: a small, text-led route through Rockfleet, Mayo, evidence boundaries, and one clearly labelled Irish learning interaction.

## Preview locally

From the repository root:

```sh
python3 -m http.server 4173 --directory web/rockfleet
```

Open [http://localhost:4173](http://localhost:4173).

The page is static and has no build step, network dependency, audio playback, account, or deployment configuration. It intentionally does not use unreviewed audio or documentary imagery.

## Review route

1. Read the Rockfleet opening and the orientation diagram.
2. Open each evidence disclosure and check the distinction between record, interpretation, and provisional content.
3. Try the Irish phrase interaction with a wrong choice, then the correct choice.
4. Use the theme control and test keyboard focus, browser zoom, and reduced-motion settings.
5. Follow the native-route section at the end; it describes the bounded iOS demonstration without pretending this page is the app.

The copy is aligned to the Mayo county pack and the project’s Rockfleet source-review notes. Before hosting, confirm the public source links, rights language, and the native TestFlight/recorded-walkthrough destination.
